# Установка и первый запуск AnimeSoul

> Инструкция относится только к архивному Vinext/Electron-стеку. Для текущей
> Python + React версии используйте [`../../app/README.md`](../../app/README.md).

## Варианты запуска

- `AnimeSoul Setup` — Windows-установщик с выбором папки, ярлыком на рабочем столе и пунктом меню «Пуск».
- Portable EXE — приложение без установки.
- `Запустить AnimeSoul.bat` — прежний способ запуска из распакованной папки проекта.

Установщик и portable EXE собираются командой `npm run desktop:build`. BAT остаётся независимым запасным вариантом.

При запуске установленной или portable-версии сначала открывается лаунчер AnimeSoul. В нём доступны:

- запуск сайта в обычном браузере;
- запуск полноценного desktop-окна;
- раздел настроек с портом и публичным ключом YummyAnime;
- повторная проверка порта и ключа перед запуском.

Выбор режима и параметры сохраняются локально, поэтому проходить мастер заново при каждом запуске не требуется.

## Мастер первого запуска

При первом запуске необходимо указать:

1. Порт сайта. Значение по умолчанию — `3001`.
2. Собственный публичный application key YummyAnime.
3. Где открывать AnimeSoul: в отдельном desktop-окне или в обычном браузере.

Чтобы получить ключ, откройте [официальную документацию YummyAnime API](https://api.yani.tv/swagger), найдите раздел **Introduction**, нажмите ссылку **here**, авторизуйтесь и создайте новое приложение. Для AnimeSoul скопируйте **Public token**. Приватный токен вводить не нужно. Согласно документации API предназначен только для личного использования.

Огромная благодарность разработчикам YummyAnime за предоставление API. Подобная открытость сегодня встречается редко, и только благодаря их работе стало возможным создание AnimeSoul.

AnimeSoul намеренно не включает единый публичный ключ в open-source код: нам неизвестно, разрешено ли распространять его таким образом и как общая нагрузка всех установок отразится на доступности API. Поэтому каждый пользователь создаёт собственный ключ. При личном использовании ключом можно поделиться с несколькими друзьями, учитывая правила YummyAnime и общую нагрузку.

Программа проверяет выбранный порт и следующий порт, который нужен локальному сервису сохранений. Ключ проверяется отдельным запросом к YummyAnime. Пустой, отклонённый или недоступный ключ не сохраняется.

Настройки находятся в локальном `animesoul.config.json` и не попадают в Git. При закрытом AnimeSoul файл можно отредактировать вручную:

```json
{
  "_comment": "Параметры локального запуска AnimeSoul",
  "sitePort": 3001,
  "yummyAnimeToken": "your_public_application_token",
  "launchMode": "desktop"
}
```

Допустимые режимы: `desktop` и `browser`. Порт хранилища вычисляется автоматически как `sitePort + 1`.

## Возможные ошибки

- «Порт занят» — закройте программу, использующую указанный порт, либо выберите другой.
- «YummyAnime отклонил ключ» — проверьте публичный application key и повторите ввод.
- «Не удалось связаться с YummyAnime» — проверьте интернет, VPN, брандмауэр и доступность API.
- После ручного изменения JSON полностью перезапустите AnimeSoul.

Личные ключи не должны добавляться в исходный код, README, `.env.example` или Git.
