# Локальные данные AnimeSoul

При запуске через `Запустить AnimeSoul.bat` приложение автоматически создаёт здесь файл:

`animesoul-storage.json`

Он содержит профили, папки, избранное, прогресс просмотра, историю, отслеживания, темы и настройки плеера. Сам файл исключён из Git, чтобы личные данные не попадали в репозиторий.

Формат имеет номер версии. После обновления AnimeSoul старые данные и импортированные конфигурации автоматически дополняются новыми полями со значениями по умолчанию.
