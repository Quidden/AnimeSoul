## Восстановление

Архивный ref открывается в отдельной рабочей копии, чтобы не перезаписать новую работу.
Приватные настройки и подпись берутся из защищённой копии, никогда из Git.
После новых production-записей нельзя просто вернуть старую БД: финальное переключение потребует своего проверенного переноса и отката.
