# 100 вымышленных пользователей

По просьбе пользователя локальная БД наполнена 100 вымышленными аккаунтами с настоящими
Argon2id-хешами и отдельными паролями. Это обычные web-аккаунты без административных прав.
Почты находятся в зарезервированной зоне example.invalid; внешняя доставка не выполняется.
Профили не индексируются. Тексты — вымышленные впечатления и обсуждения, не отзывы реальных людей.

```sh
pnpm demo:community
pnpm demo:community verify
```

Генератор разрешён только для существующей loopback-БД animesoul на 54329 вне production.
До создания выполняются pg_dump/проверка backup и снимок исходных аккаунтов/библиотек/UUID.
Все 100 аккаунтов и связи создаются одной транзакцией. Повторный запуск сохраняет пароли,
активность и пользовательские изменения; повреждённый manifest или отсутствующие аккаунты
останавливают генерацию, а не перезаписывают данные. verify сверяет все 100 паролей.

В игнорируемом `artifacts/demo-community` находятся CSV и TXT «Логины-и-пароли», приватный manifest,
backup и проверка сохранности. Логин на `/account` — почта, а не ник.
Sora_NightTea имеет большой список друзей и заявки; Nami_VinylSky/Kira_VinylSky отправили ему заявки,
а Rin_VinylSky/Yuna_VinylSky могут проверить полученные запросы по данным TXT.
Для точного направления смотрите сценарий конкретной строки файла: он является источником.

Профили различаются вкусами, присутствием и аудиториями. Есть подборки с заметками, оценки,
прогресс реальных серий, друзья, подписки, заявки и блокировки. Посты, рецензии, комментарии,
ответы и таймкоды читаются через настоящие API. Прогресс использует уже существующие ID серий.
Генератор не запускает фоновый бот: активность подготовлена один раз и далее доступна для ручных тестов.
Для проверки интерфейса: `/community`, профиль, `/friends`, `/library`, аниме и серия.
