# Оформление сайта

В `main` восстановлен привычный стиль прежнего сайта на Next.js/React.
Тёмный фон, стеклянная шапка, компактные карточки и открытая композиция профиля относятся
к действующему интерфейсу. [Карта страниц](../architecture/SITE_MAP.ru.md) описывает маршруты.

| Область                                               | Стили в `apps/web/styles` | Компоненты / страницы                                |
| ----------------------------------------------------- | ------------------------- | ---------------------------------------------------- |
| Основа, цвета, типографика, общие элементы            | `base.css`                | `app/layout.tsx`, `components/Icon.tsx`              |
| Шапка, поиск, меню и подвал                           | `header.css`              | `SiteHeader.tsx`, `SiteFooter.tsx`                   |
| Главная и баннер                                      | `home.css`                | `app/page.tsx`                                       |
| Каталог, фильтры и карточки                           | `catalog.css`             | `app/catalog/page.tsx`, `AnimeCard.tsx`              |
| Информация об аниме                                   | `anime.css`               | `app/anime/[slug]/page.tsx`                          |
| Профиль, затухающая обложка и компактная идентичность | `profile.css`             | `ProfileHeader.tsx`, `app/users/[username]/page.tsx` |

`apps/web/styles/tokens.css` задаёт общие цвета, радиусы и слои. `pnpm styles:check`
проверяет новые цвета вне токенов по сохранённому baseline. Текущий интерфейс также
использует `anime-watch.css`, `community.css`, `header-tabs.css`, `greeting.css`,
`scroll-compass.css` и `scroll-reveal.css`. Главная, каталог, библиотека и плеер
используют общие токены; настройки оформления аккаунта сохраняют выбранную палитру.

`apps/web/app/globals.css` импортирует CSS разделов и содержит общие правила.
`ScrollReveals` постепенно показывает секции, сохраняя читаемый SSR без JavaScript
и учитывая уменьшение движения. `apps/admin/app/globals.css` относится к самостоятельной
защищённой админке: [возможности](../operations/ADMINISTRATION.ru.md).

Обложка профиля занимает ширину экрана и затухает к области аватара. `ProfileHeader`
измеряет прокрутку, обновляет `--profile-collapse` и выводит компактный аватар/ник через React portal
в body над шапкой сайта. Это визуальное поведение, не изменение настроек аккаунта.
Публичные содержимое и ссылки рендерятся сервером; клиентский JavaScript добавляет меню и анимацию.

## Сохранённый прототип

[minimal-concepts.html](minimal-concepts.html) — исторический самостоятельный макет вариантов.
Его кнопки, localStorage, обозначения плеера/провайдеров и мобильные варианты не являются
реализацией возможностей `main` и не подключены к API. Макет сохранён для сравнения;
он не входит в приложение и исключён из автоматического форматирования.

Доверенные изображения — в [описании медиа](../../apps/web/public/ASSETS.ru.md).
Для новой визуальной правки меняется профильный CSS/компонент и проверяется реальная страница,
а не исторический прототип. Стили нового дизайна и перенос функций — отдельные задачи.
