[Публикации и обсуждения](operations/CONTENT.ru.md) · [100 вымышленных пользователей](operations/DEMO_COMMUNITY.ru.md).

Документация актуализирована по текущим изменениям сайта 6 ноября 2026 года. Основной проект — новый веб-стек;
Android находится в отдельном репозитории, desktop исключён из разработки.
Старые исходники/данные сохранены отдельно; весь перенос функций ещё не завершён.

## Как читать статусы

«Работает» означает существующую реализацию и её указанные проверки.
«Только схема» означает таблицы/контракты без завершённого сценария.
«Планируется» означает отсутствие текущего маршрута или сервиса.
Demo-профиль не является настоящим входом; HTML админки с HTTP 200 не даёт административный доступ.
Источники кода и проверок имеют приоритет над иллюстрациями и целевым планом.

При изменении URL, DTO, таблицы, настроек или команды обновляются обе языковые версии
соответствующего документа. `pnpm docs:check` проверяет локальные ссылки, `pnpm format:check` — оформление.
Документация старого стека остаётся в архиве; инструкции Android принадлежат `AnimeSoulMobile`.
