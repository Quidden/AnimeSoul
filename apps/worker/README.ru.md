# Фоновые задачи

`main.mjs` запускает строгий TypeScript-исполнитель `apps/api/src/providers/catalog-worker.ts`.
Он собирается вместе с API. Каталог поступает только из Kodik; YummyAnime — резерв просмотра. Действующая очередь каталога хранится в PostgreSQL: аренда,
сохранённый курсор Kodik, счётчики выпусков, ограниченные повторы и наблюдаемое состояние.

Запуск: `pnpm catalog:sync`, затем `pnpm catalog:worker`. `CATALOG_WORKER=true` включает
исполнитель в `pnpm dev`. По умолчанию выключен; требуется настроенная БД. Redis не используется.
В полном [Docker-стеке](../../docs/operations/DOCKER.ru.md) worker запускается отдельным
контейнером автоматически, а миграции завершаются до его запуска.
Ключи не попадают в задания или публичные логи. Контроль и проверка ID доступны через admin.
[Инструкция каталога](../../docs/operations/CATALOG.ru.md).

Проверки конкуренции, восстановления, отката страницы и остановки входят в `pnpm db:verify`
и обязательные PostgreSQL-тесты CI. Будущие задачи: обработка медиа, почта, сверка платежей
и показатели. Они пока не подключены к этому исполнителю.
