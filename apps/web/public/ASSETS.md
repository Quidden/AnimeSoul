# Profile media assets

The illustrations in `profile-presets/` were created for AnimeSoul. The animated
SVGs respect the viewer's reduced motion preference. Preset IDs and labels are
defined by the website's `profile_media.py`; add trusted library assets there.

`giphy-attribution.png` is the unmodified official Powered by GIPHY mark from
[GIPHY's attribution pack](https://media.giphy.com/giphy-attribution-marks.zip),
used for the embedded GIF picker. GIPHY GIFs are served directly by GIPHY and
are not stored among these assets.

Development catalog posters link to the same public CDN URLs returned by the archived local catalog for Frieren, Violet Evergarden and Your Name. They are preview references, not bundled artwork or a production content license. Production metadata/media sourcing remains a separate migration gate.
