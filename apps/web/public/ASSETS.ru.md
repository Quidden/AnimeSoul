# Медиа профиля и сайта

Next.js выдаёт эту папку от `/`. Сейчас здесь `animesoul-icon.png`
и доверенные иллюстрации `profile-presets/`:

| Тип     | Файлы                                                                          |
| ------- | ------------------------------------------------------------------------------ |
| Аватары | `avatar-cat.svg`, `avatar-kitsune.svg`, `avatar-moon.svg`, `avatar-orbit.svg`  |
| Обложки | `banner-dawn.svg`, `banner-night.svg`, `banner-sakura.svg`, `banner-stars.svg` |

Иллюстрации созданы для AnimeSoul. Анимированные пресеты учитывают предпочтение уменьшенной анимации.
Demo-профиль выбирает пути в [fixtures.ts](../../../packages/database/src/fixtures.ts),
[ProfileHeader.tsx](../components/ProfileHeader.tsx) отображает публичные avatar/banner.
Пресеты перечислены в packages/contracts/src/profile-media.ts, выбираются владельцем в /account и сохраняются через /api/account/profile. Произвольные внешние URL не принимаются.

Владелец профиля может выбрать пресет, загрузить JPEG/PNG/WebP/GIF или выбрать анимацию из
результатов GIPHY по запросу `anime`. Пикер показывает атрибуцию и загружает GIPHY напрямую
из браузера с отдельным публичным web-ключом, передаваемым во время работы. БД хранит только
ID GIPHY; копии и URL GIF на нашем сервере не кешируются. Загруженные файлы после полной
проверки сохраняют исходные байты, хранятся вне `public/` и выдаются с учётом видимости профиля.
Редактирование требует сессию владельца и CSRF. См. [эксплуатацию медиа](../../../docs/operations/ACCOUNTS.ru.md).

Шесть снимков `images/player-preview/*-full.jpg` показывают настоящий плеер AnimeSoul:
навигацию, качество, скорость, изображение, продолжение и полный экран. Каждый сохраняет
полный кадр плеера и открывается с увеличением в галерее подписки. Старые `navigation.jpg`
и `settings.jpg` со звёздным небом сохранены как прежние материалы.

Интерактивное демо использует собственную нарисованную анимированную сцену «Путь к городу»
в `media/player-demo/`: WebM без звука длительностью около 18 секунд в 1280×720 и 640×360,
а также JPEG-постер. Оба качества содержат одну сцену. Код плеера загружается по запросу,
видео запускается после нажатия пользователя. Сторонние кадры в проект не включены.
См. [подписки](../../../docs/operations/SUBSCRIPTIONS.ru.md).

Исходник сцены: [generate-player-demo.html](../../../scripts/media/generate-player-demo.html).
Запустить `node scripts/media/generate-player-demo.mjs`, открыть `http://127.0.0.1:18890`
в Chromium и нажать «Создать фрагмент». Три полученных файла сохранить с теми же именами
в `apps/web/public/media/player-demo/`. Локальный инструмент не использует внешнее медиа или сервисы.

Постеры demo-аниме используют публичные CDN-адреса из старого локального каталога
для Фрирен, Вайолет Эвергарден и «Твоего имени». Это ссылки предпросмотра, а не включённые
в репозиторий изображения или лицензия на production-контент. Источник production-медиа — отдельное условие миграции.
