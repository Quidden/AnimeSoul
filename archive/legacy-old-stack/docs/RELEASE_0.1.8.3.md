# AnimeSoul 0.1.8.3 Beta

Небольшое beta-обновление библиотеки, статистики и Windows-лаунчера.

## Что нового

- Страница статистики получила календарь активности в стиле GitHub:
  - месяцы и выбранный год;
  - переключение между годами;
  - фиксированный блок деталей дня со списком просмотренных серий;
  - дополнительные графики, жанры, время просмотра и пересмотры.
- У каждой серии появился компактный глаз для ручной отметки просмотра.
- Глаз в заголовке сезона отмечает или снимает отметку сразу со всех его серий.
- Ручные отметки учитывают длительность, завершения и календарь статистики.
- В миниатюрах избранного и папок выровнены названия, статусы, прогресс и действия.
- Тайтлы можно удалять прямо из миниатюр.
- Последнюю удалённую папку можно восстановить до следующего удаления.
- Windows-лаунчер теперь позволяет:
  - выбрать запуск в браузере или desktop-окне;
  - открыть настройки порта и публичного API-ключа;
  - сохранить параметры для следующих запусков.

## Исправления

- Состояние свёрнутых секций главной страницы сохраняется между переходами и перезапусками.
- Исправлена верстка прогресса и действий в компактных блоках библиотеки.
- Детали календарного дня больше не меняют высоту всей секции.

## Ограничения beta

- Доступность видео, озвучек, кадров и точных таймкодов зависит от внешнего API и видеопровайдера.
- Совместное управление плеером гарантировано только для источников, передающих нужные события через `postMessage`.
- Для работы требуется собственный публичный application key YummyAnime; приватный ключ не нужен.
