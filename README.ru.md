# AnimeSoul — новый веб-проект

Основа сайта: TypeScript, Next.js/React, NestJS/Fastify и PostgreSQL/Prisma.
Android ведётся в самостоятельном репозитории. Разработка десктопного приложения прекращена.

Основная рабочая папка — `C:/Users/dogem/Documents/AnimeSoul`, ветка `main`.
Старая локальная версия вместе с настройками, базами и релизами сохранена в соседней
`C:/Users/dogem/Documents/AnimeSoulArchive`, ветка `codex/legacy-local-2026-10-06`.
Подключены основной Kodik и отключаемый резерв просмотра YummyAnime, аккаунты, приватная библиотека и вход в админку с MFA.
Страницы серий, таймкоды, новый прогресс и свой HLS-плеер с embed fallback реализованы.
Реализованы загрузка медиа/GIPHY, страницы персонажей, общий поиск и поиск по кадру, подписки и аналитика админки.
Текущий интерфейс включает расписание выходов, навигацию по франшизе, ленту сообщества,
обновлённые каталог, библиотеку и управление плеером, общие визуальные токены. Поиск по кадру
ограничивает бюджет провайдера и использует подписанный внутренний канал посетителей;
публичные ответы каталога кешируются отдельно от приватных данных.
Подробности: [ход миграции](docs/migration/STATUS.ru.md), [просмотр](docs/operations/PLAYBACK.ru.md),
[аккаунты](docs/operations/ACCOUNTS.ru.md) и [администрирование](docs/operations/ADMINISTRATION.ru.md).
Публичный запуск и реальные платежи остаются отдельными этапами.

## Локальный запуск

Основной запуск всего проекта — Docker Desktop с Linux-контейнерами:

```sh
docker compose up -d --build --wait
```

Сайт, API, админка, обработчик и PostgreSQL работают в контейнерах. На Windows
[Start AnimeSoul.bat](scripts/windows/Start%20AnimeSoul.bat) выполняет эту команду,
при первом запуске создаёт `.env` и открывает браузер. Закрытие окна не останавливает сайт.
Остановка: `docker compose stop`. [Запуск, данные и сервер с HTTPS](docs/operations/DOCKER.ru.md).

Для разработки с обновлением при правках можно использовать Node.js:

Нужны Node.js 24.7+ (ветка 24) и pnpm 11.25.0:

```sh
pnpm install --frozen-lockfile
pnpm run setup
pnpm dev
```

В Windows для этого режима можно запустить [Start AnimeSoul Dev.bat](scripts/windows/Start%20AnimeSoul%20Dev.bat).
Он запускает этот TypeScript-проект и сохраняет существующий `.env`.
Если pnpm не установлен, используется `npx` с закреплённой версией pnpm 11.25.0;
для первого скачивания потребуется интернет.

Сайт: http://localhost:8021 · API: http://127.0.0.1:8020 · админка: http://localhost:8022.
Новый checkout начинает с demo-данных без перенесённых аккаунтов. Приватные БД и медиа
восстанавливаются отдельно; вход и перенос профиля доступны на `/account`: [инструкция](docs/operations/ACCOUNTS.ru.md).
Индексация локального сайта отключена. Ctrl+C останавливает только сервисы этого запуска.

Полный Docker-запуск сам поднимает PostgreSQL и применяет миграции.
Redis пока не используется приложениями и включается отдельно профилем `cache`.
Прежняя команда `infra:up` оставлена для отдельной инфраструктуры при разработке;
не запускайте её одновременно с полным стеком на тех же портах.

DEMO_CATALOG=false в приватном .env переключает API на PostgreSQL.
Тестовое наполнение запрещено в production и не создаёт администратора.
Проверка готовности API возвращает 503, пока настоящая база не отвечает.
Seed добавляет только demo-аниме, без профиля/аккаунта; подключение БД не переносит старые данные.
На этой машине текущие данные перенесены в PostgreSQL 18 в Docker; исходный native-кластер
и его настройки сохранены. `LOCAL_POSTGRES=false` подключает утилиты к базе Docker.
`LOCAL_POSTGRES=true` остаётся отдельным вариантом для native PostgreSQL при `pnpm dev`.
Demo-предпросмотр по-прежнему работает без БД; просмотр требует импортированного каталога и разрешённых источников.

## GitHub и образы

Сайт находится в `main`; прежнее приложение сохранено в `master`. Автоматические запуски
тестов GitHub удалены. Образы API/сайта/админки/миграций публикуются вручную через
**Actions → Publish containers → Run workflow**. [Публикация и запуск GHCR](docs/operations/GITHUB.ru.md).
Отдельный приватный тестовый образ `quiddens/animesoul-dev` размещён на Docker Hub:
[инструкция](docs/operations/DEV_IMAGE.ru.md). [Развёртывание своего сайта](docs/operations/SELF_HOSTING.ru.md)
описывает домены, приватные настройки, запуск, резервные копии и обновления.
Dockerfile остаётся в `infra/docker/`; секреты передаются контейнерам при запуске.
