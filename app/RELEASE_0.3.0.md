# AnimeSoul 0.3.0

September 30, 2026 · [Русский](RELEASE_0.3.0.ru.md)

The new library interface is now the default and no longer in beta. This release includes Windows and Android.

- Fixed light-theme contrast across text, buttons, menus, settings and library pages.
- Phone navigation now lives at the bottom. Watch opens phone playback or the paired PC remote.
- Mobile episodes use a list without the side carousel; anime information, trailer and actions live in the About tab.
- Mobile settings now use categories and full-screen panels, with corrected Android system insets and no bottom gap.
- Fixed favorites/folder cards, button sizing and dialogs overlapping playback navigation.
- Mobile status messages use a compact line inside bottom navigation.
- The launcher automatically checks the latest release at startup and notifies about updates.
- Added desktop Discord Rich Presence integration.
- The home screen retains its full-screen trailer/poster; profile compatibility is preserved.

## Downloads

- `AnimeSoul-Setup-0.3.0.exe` — Windows x64 installer.
- `AnimeSoul-0.3.0-android-arm64.apk` — Android ARM64.

Install over the existing application without uninstalling to retain local data.
