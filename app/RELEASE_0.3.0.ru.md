# AnimeSoul 0.3.0

30 сентября 2026

Новый интерфейс медиатеки вышел из беты и стал основным. Релиз включает Windows и Android.

- Исправлен контраст светлой темы: текст, кнопки, меню, настройки и страницы библиотеки.
- На телефонах шапку заменяет нижняя навигация с поиском, библиотекой и меню «Смотрю». В нём доступны продолжение на телефоне и пульт ПК.
- Серии показаны удобным списком без боковой карусели; постер, описание, трейлер и действия доступны во вкладке «Об аниме».
- Настройки адаптированы для телефона: категории, поиск и полноэкранные панели. Исправлены системные отступы Android и пустое место снизу.
- Исправлены карточки избранного и папок, размеры кнопок и перекрытия диалогов.
- Уведомления на телефоне перенесены в компактную строку нижнего меню.
- При запуске через приложение автоматически проверяется последняя версия и появляется уведомление об обновлении.
- Добавлена интеграция Discord Rich Presence для настольного приложения.
- Главная сохраняет полноэкранный трейлер или постер. Формат профиля остаётся совместимым.

## Файлы

- `AnimeSoul-Setup-0.3.0.exe` — установщик Windows x64.
- `AnimeSoul-0.3.0-android-arm64.apk` — Android ARM64.

Устанавливайте поверх существующей версии, без удаления приложения, чтобы сохранить локальные данные.
