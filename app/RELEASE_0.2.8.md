# AnimeSoul 0.2.8

Release date: **September 24, 2026**.

## Local network devices

- Pair Windows and Android with an IPv4 address and a single-use four-digit code. The settings screen shows each device's connection status.
- Paired devices synchronize saves automatically, alongside the existing Google Drive save flow.
- Transfer downloaded MP4 episodes in either direction with size and SHA-256 verification into the normal offline library.
- Control playback, seeking, episodes and titles on another device with separate access and priority settings.

Both apps must stay open on a trusted local network. Android background transfers and legacy HLS package transfer are not supported yet.

## Release files

- `AnimeSoul-Setup-0.2.8.exe` — Windows x64 installer;
- `AnimeSoul-0.2.8-android-arm64.apk` — Android 7.0+ ARM64;
- `AnimeSoul-0.2.8-SHA256SUMS.txt` — checksums.

Updating the signed APK preserves installed data and downloaded episodes.
