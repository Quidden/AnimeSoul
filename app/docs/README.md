# Документация AnimeSoul

Этот каталог описывает актуальную реализацию из `app/` версии **0.2.5**. Пути в
документах указаны от корня репозитория `AnimeSoul/`, если явно не сказано иное.
Код является источником истины; документы сверены с ним на 30 августа 2026 года.

| Документ | Что содержит | Кому нужен |
| --- | --- | --- |

История изменений хранится в `app/RELEASE_*.md`. Она фиксирует поведение
конкретных релизов и не заменяет технические справочники.

## Область действия

- `app/` — единственная актуальная продуктовая реализация.
- `legacy-old-stack/` — архивная реализация, используемая как источник для
  одноразового импорта и двустороннего переноса сохранений.
- Документация в `legacy-old-stack/` относится только к старому Vinext/Electron
  коду. Её маршруты, процессы и стили нельзя переносить в текущую архитектуру
  без проверки.

## Как поддерживать документы

При изменении кода одновременно обновляйте соответствующий контракт:

1. Новый или изменённый маршрут — `API_REFERENCE.md` и, при изменении цепочки,
   `ENTRY_POINTS_AND_FLOWS.md`.
2. Новое сохраняемое поле — `DATA_MODEL.md`, TypeScript-типы, миграцию и тесты
   совместимости.
3. Новый CSS-файл, токен или смена порядка импорта — `STYLES.md` и импортный
   манифест.
4. Перенос ответственности между модулями — `PROJECT_MAP.md`,
   `ARCHITECTURE.md` и roadmap.
5. Пользовательское изменение — соответствующий `RELEASE_*.md`.

Для внутреннего API дополнительно проверяйте автоматически созданные FastAPI
страницы `/docs` и `/openapi.json` на запущенном backend.
