## Updating images

Use a demo profile and separate data directory, build the current platform frontend, navigate the actual UI, wait for rendering and capture without editing controls/content into the image. Avoid credential/cloud-account/debug screens. Record date, app version, platform and viewport. Keep descriptive filenames in screenshots/ and captions/alt text in both languages. A responsive desktop browser capture must not be labeled as a native Android device capture.
