# AnimeSoul

## Десктопное приложение для Windows

AnimeSoul можно запускать не только в браузере, но и как отдельное Windows-приложение. Десктопная версия содержит тот же каталог, плеер, библиотеку, отслеживание, статистику, темы и настройки.

Запуск из исходников:

```powershell
npm install
npm run desktop
```

Сборка переносимого `.exe`:

```powershell
npm run desktop:build
```

Готовый файл появится в каталоге `desktop-dist`. Он не требует отдельно открывать браузер или запускать BAT-файл.

Данные десктопной версии хранятся независимо от файлов программы:

```text
%APPDATA%\AnimeSoul\data\animesoul-storage.json
```

При первом запуске из папки проекта приложение автоматически копирует существующий `data/animesoul-storage.json`, если в профиле десктопной версии ещё нет сохранений. Перенос на другое устройство также работает через экспорт и импорт конфигурации в интерфейсе.

Если браузерная версия находится в `Документы\AnimeSoul`, десктоп автоматически использует её файл `data\animesoul-storage.json`. Избранное, папки, прогресс, история и настройки в таком случае общие для обоих вариантов запуска.

Масштаб десктопного интерфейса:

- `Ctrl` + колёсико мыши — увеличить или уменьшить;
- `Ctrl` + `+` / `Ctrl` + `-` — изменить масштаб;
- `Ctrl` + `0` — вернуть 100%;
- `F11` — полноэкранный режим.

Выбранный масштаб сохраняется после закрытия приложения.

Локальная аниме-библиотека с каталогом YummyAnime, внешними видеоплеерами, прогрессом просмотра и пользовательскими коллекциями. Видео не сохраняются на компьютере: приложение получает метаданные и ссылки на встроенные плееры через API.

## Основные возможности

- Каталог с обложками, статусами выхода, жанровыми фильтрами, рейтингами, случайным выбором и поисковыми подсказками.
- Франшизы с сезонами, фильмами, OVA/ONA и спецвыпусками в порядке просмотра API.
- Сезоны, серии, русские озвучки, длительность и выбор источника воспроизведения.
- Продолжение с сохранённой серии и момента просмотра.
- Прогресс каждой серии, сезона, тайтла и папки.
- Ручная отметка серии или целого сезона просмотренными с корректным учётом времени и завершений в статистике.
- Избранное и пользовательские папки с заметками и ручной сортировкой.
- Удаление элементов прямо из миниатюр библиотеки и восстановление последней удалённой папки.
- История и список «Смотрю сейчас» с возможностью отключения и очистки.
- Отдельная статистика: время просмотра, серии, фильмы, спецвыпуски, завершённые тайтлы, любимые жанры, пересмотры и графики активности.
- Календарь просмотров в стиле GitHub с деталями по дням, месяцами и переключением между годами.
- Отслеживание новых серий всей франшизы для всех или выбранных озвучек с быстрым запуском новинки.
- Автопереключение серии, автозапуск и пропуск опенинга/эндинга для совместимых плееров Kodik.
- Настраиваемое расположение панели плеера.
- Готовые и пользовательские цветовые темы.
- Экспорт, импорт и переключение локальных профилей конфигурации.
- Автоматическое хранение пользовательских данных в `data/animesoul-storage.json`.
- Версионирование и миграция старых конфигураций при добавлении новых функций.

## Быстрый запуск в Windows

1. Установите [Node.js 22 или новее](https://nodejs.org/).
2. Скачайте и распакуйте архив из каталога `releases`.
3. Запустите `Запустить AnimeSoul.bat`.
4. При первом запуске укажите публичный токен YummyAnime.

Скрипт установит зависимости, запустит сайт и откроет `http://localhost:3001/`.

Установщик и portable-версия открывают отдельный лаунчер. В нём можно выбрать браузер или desktop-окно, изменить порт и публичный API-ключ без ручного редактирования файлов. Сохранённые параметры используются при следующих запусках.

## Перенос сохранений

Через интерфейс:

1. Нажмите кнопку выгрузки конфига в верхнем меню старой версии.
2. В новой версии нажмите кнопку загрузки и выберите полученный JSON-файл.
3. Переключитесь на импортированный профиль.

Через файл проекта:

1. Полностью закройте AnimeSoul.
2. Скопируйте `data/animesoul-storage.json` из старой папки проекта.
3. Поместите файл в каталог `data` новой версии с заменой.
4. Запустите `Запустить AnimeSoul.bat`.

Оба способа подходят для обновления приложения и переноса на другой компьютер. Миграции конфигурации автоматически дополняют старые сохранения новыми полями.

```powershell
npm run build
npm run start
```

## Переменные окружения

```dotenv
YUMMYANIME_TOKEN=your_public_application_token
```

Это публичный application token текущего личного прототипа. Он используется только серверным API-маршрутом и не попадает в клиентскую сборку. Приватный токен для работы приложения не нужен и в репозитории не хранится.

## Стек

- TypeScript
- React 19
- Next.js 16 API conventions
- vinext + Vite
- Tailwind CSS 4
- YummyAnime API
- Kodik и другие iframe-плееры, предоставленные API
- локальный Node.js-сервис для сохранения данных в JSON-файл
- `localStorage` как резервное зеркало и источник для первого переноса

## Ограничения

- Доступность видео и озвучек определяется внешними поставщиками.
- Управление временем, автопропуск и точный прогресс требуют поддержки `postMessage` конкретным iframe-плеером.
- Данные пользователя сохраняются в `data/animesoul-storage.json`. Экспорт конфигурации остаётся резервной копией и способом переноса.
- Проверка отслеживаемых релизов выполняется при открытии главной страницы и повторяется каждые пять минут, пока она открыта.

## Правовой статус

Проект предназначен для личного прототипирования. Перед публичным распространением проверьте условия YummyAnime API, видеопровайдеров и правообладателей.
