Огромная благодарность разработчикам YummyAnime за предоставленный API. В наше время открытый API для подобных проектов встречается редко, и только благодаря их работе стало возможным создание AnimeSoul. Автор проекта от всей души благодарит команду YummyAnime.

По умолчанию 3001. Следующий порт (3002) используется локальным хранилищем.

Где взять ключ: откройте официальную документацию YummyAnime API, в разделе Introduction нажмите ссылку here, авторизуйтесь и создайте новое приложение. Скопируйте его Public token — приватный токен AnimeSoul не нужен.

Ключ будет проверен запросом к API перед сохранением. API разрешён только для личного использования.

Мы не знаем, разрешено ли безопасно распространять один публичный ключ внутри open-source проекта и как общая нагрузка повлияет на его работу. Поэтому AnimeSoul не содержит общего ключа: каждый пользователь создаёт собственный. При личном использовании вы можете поделиться своим ключом с несколькими друзьями, принимая во внимание общую нагрузку и правила YummyAnime.
