# AnimeSoul 0.1.8.2 Beta

Исправления совместного просмотра:

- в режиме «Все управляют на равных» пауза и продолжение просмотра от любого участника передаются всей комнате;
- устаревшее состояние хоста больше не применяется повторно и не возвращает участника к старому таймкоду;
- удалённая команда продолжения сравнивается с фактическим состоянием плеера и больше не пропускается;
- сайт и десктоп проверяют версию протокола совместного просмотра и показывают понятную ошибку при запуске старого сервера;
- сохранена совместимость передачи роли хоста между сайтом и десктопным приложением.

После обновления всем участникам необходимо полностью закрыть старую версию AnimeSoul, запустить 0.1.8.2 и создать новую комнату.
